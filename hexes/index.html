Hexes Hex Editor BETA

The ultimate hex editor for the TI-84 Plus CE calculator!

Hexes is a hex editor utility for the TI-84 Plus CE and TI-83 Premium CE calculators and their derivatives, designed to be pleasant and friendly to use, providing a clean interface for viewing and editing files directly on your calculator.

Releases

This program is still in beta! However, you can try out the latest build from the GitHub repository.

Installation

Go to releases (not applicable currently as there are no releases of the program yet) and download HEXES.8xp. Transfer it to your calculator using TI Connect CE or TILP or whatever linking program you desire.

! WARNING !

Depending on the version of TI-OS on your calculator, you may need to use the jailbreak. See more details here.

Building

First, make sure you have the CE C Toolchain installed on your computer. See this site for instructions and details.

Navigate to the root folder of the project, and simply run the command make .

HEXES.8xp will be created in the bin/ directory.
